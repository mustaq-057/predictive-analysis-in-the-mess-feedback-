# Server Configuration

The application is configured to run on **Port 3005**.

## Running the Application

```bash
npm run dev
```

Access at:
- `http://localhost:3005/student`
- `http://localhost:3005/admin`

## Production Mode

```bash
# Build first
npm run build

# Then run
npm run start
```

---

## Available Commands

| Command | Port | Description |
|---------|------|-------------|
| `npm run dev` | 3005 | Run development server |
| `npm run start` | 3005 | Run production server |
